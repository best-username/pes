# pes

Selection tasks for the Genesis AI Product Engineering School. Each task is self-contained: its code,
documentation, tests and evaluation live in its own folder.

| Folder | Task |
|---|---|
| [`wikipedia-interest-analysis/`](wikipedia-interest-analysis/) | An Agent Skill that measures how attention to a topic changes over time from Wikipedia pageviews, in one or several language editions, and writes a shareable HTML report |
